# 03 - Configuration Reference

Configuration options, JSON schema, and tuning parameters for `hmg-phone-profiles`.

---

## 1. Configuration File Location

The runtime configuration is stored on the head unit filesystem at:

```
/data/nemesis/apps/hmg-phone-profiles/config.json
```

This file is automatically generated on package installation by `scripts/post.sh` if it does not already exist.

---

## 2. Configuration Schema & Example

```json
{
  "version": 1,
  "conflict_policy": "p1",
  "auto_learn_wifi": true,
  "dismiss_consent": true,
  "seat_recall_delay_ms": 1000,
  "poll_interval_sec": 5,
  "phones": [
    {
      "name": "Pixel 11 Pro XL",
      "bt_mac": "AA:BB:CC:11:22:33",
      "wifi_mac": "02:00:00:11:22:33",
      "assigned_driver": 1,
      "priority": 1
    },
    {
      "name": "iPhone Duo",
      "bt_mac": "DD:EE:FF:44:55:66",
      "wifi_mac": "02:00:00:44:55:66",
      "assigned_driver": 2,
      "priority": 2
    },
    {
      "name": "Samsung S26 Ultra",
      "bt_mac": "11:22:33:AA:BB:CC",
      "wifi_mac": null,
      "assigned_driver": 0,
      "priority": 0
    }
  ]
}
```

---

## 3. Field Definitions

### Top-Level Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| `version` | Integer | `1` | Configuration schema version. |
| `conflict_policy` | String | `"p1"` | Resolution strategy when multiple paired phones are present (`"p1"`, `"p2"`, or `"manual"`). |
| `auto_learn_wifi` | Boolean | `true` | When `true`, dynamically associates new Wi-Fi MACs with active Bluetooth devices. |
| `dismiss_consent` | Boolean | `true` | Automatically dismisses the boot warning disclaimer screen once profile is set. |
| `seat_recall_delay_ms`| Integer | `1000` | Delay in milliseconds between user switch and physical seat memory button command. |
| `poll_interval_sec` | Integer | `5` | Loop interval in seconds for background radio presence polling. |
| `phones` | Array | `[...]` | List of configured smartphone profiles. |

### Phone Object Schema

| Parameter | Type | Description |
|---|---|---|
| `name` | String | Friendly display name for the device shown in the UI. |
| `bt_mac` | String | Bluetooth hardware MAC address (colon-separated, case-insensitive). |
| `wifi_mac` | String / `null` | Associated Wi-Fi station MAC address (or `null` to auto-learn). |
| `assigned_driver` | Integer | Assigned driver profile: `1` (Driver 1), `2` (Driver 2), or `0` (Ignored). |
| `priority` | Integer | Arbitration priority order when evaluating conflict resolution. |

---

## 4. Modifying Configuration

Configuration can be modified via two methods:

### Method 1: In-Vehicle Companion App
Open **Auto Profile** from the Android app drawer or NEMESIS Manager. The touchscreen UI allows mapping detected devices, changing driver assignments, and toggling conflict policies directly on the display.

### Method 2: Command Line (ADB or SSH)
Edit the file directly using `vi` or overwrite via ADB:
```bash
adb shell "vi /data/nemesis/apps/hmg-phone-profiles/config.json"
```
Changes take effect on the next polling cycle without requiring a daemon restart.
